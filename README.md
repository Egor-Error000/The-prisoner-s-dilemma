

# Дилемма заключённого: Итеративное Моделирование и Обучение

## Обзор

Данный проект представляет собой симуляционную систему для итеративной версии классической дилеммы заключённого. Система моделирует многократные взаимодействия между агентами, применяя различные стратегии (например, Tit-for-Tat, Always Cooperate, Always Defect, Grudger, Pavlov и др.). Проект позволяет:
- Исследовать оптимальные стратегии в условиях повторяющейся дилеммы.
- Сравнивать эффективность различных подходов и моделей.
- Применять методы обучения с подкреплением (Policy Gradient) и генетические алгоритмы для оптимизации поведения агентов.
- Анализировать результаты с помощью различных архитектур нейросетей: DNN, CNN, а также рекуррентных сетей (RNN, LSTM, GRU).

## Функциональные возможности

- **Симуляция итеративной дилеммы заключённого:** моделирование N раундов взаимодействия между агентами с фиксированной матрицей выигрышей.
- **Реализация множества стратегий:** определены и протестированы стратегии из теории игр, такие как Tit-for-Tat, Suspicious TFT, Grudger, Pavlov, Detective и др.
- **Обучение агентов:** 
  - Обучение нейронных сетей (DNN, CNN) с использованием алгоритмов Policy Gradient и self-play для выработки оптимальных стратегий.
  - Применение генетического алгоритма для эволюционной оптимизации параметров моделей.
  - Использование рекуррентных архитектур (RNN, LSTM, GRU) для анализа временных зависимостей в последовательностях ходов.
- **Анализ и визуализация:** построение графиков динамики наград, уровня кооперации и сравнения эффективности различных архитектур.
- **Обеспечение воспроизводимости:** использование фиксированных random seed для NumPy, random и torch, что гарантирует воспроизводимые результаты при запуске.

## Стек технологий

- **Язык программирования:** Python 3.x
- **Математические библиотеки:** NumPy
- **Фреймворк для нейросетей:** PyTorch
- **Визуализация:** Matplotlib
- **Методы обучения и оптимизации:** Policy Gradient, self-play, генетический алгоритм, LRU-кеширование
- **Дополнительно:** Реализация стратегий на основе классических алгоритмов теории игр

```bash

```

В процессе выполнения выводятся результаты симуляций, статистика по эпизодам и строятся графики, позволяющие оценить эффективность обученных моделей и динамику сотрудничества.

## Структура кода

- **Основные модули реализации:**
  - *Имплементация стратегий:* Определены классы различных стратегий (Tit-for-Tat, Always Cooperate, Always Defect, Pavlov, Detective, и др.).
  - *Обучающие модели:* Реализованы нейронные сети для обучения оптимальной стратегии – модели DNN, CNN, а также рекуррентные сети (RNN, LSTM, GRU).
  - *Обучение с self-play и генетическим алгоритмом:* Реализованы циклы обучения с обновлением весов, оценкой наград и оптимизацией через Policy Gradient и генетические алгоритмы.
  - *Анализ результатов:* Функции для расчета метрик (уровень сотрудничества, средний reward) и визуализации динамики обучения.

## Примеры использования

### 1. Симуляция и сравнение стратегий

В файле реализовано сравнение различных стратегий агентов в условиях многократного взаимодействия. Примерный вывод:

```
Episode 0, Reward: 250, Opponent: TitForTat
Episode 25, Reward: 300, Opponent: AlwaysDefect
...
```

### 2. Обучение нейронных сетей

- **DNN:** Обучение модели на основе последних k ходов оппонента с выводом графика наград.
- **CNN:** Реализация свёрточной архитектуры для анализа временных последовательностей и сравнение с DNN.
- **Рекуррентные модели:** Обучение RNN, LSTM и GRU с оценкой динамики сотрудничества и эффективности.

### 3. Генетический алгоритм

Оптимизация параметров DNN с использованием генетического алгоритма, которая демонстрируется через графики "Best Score" и "Average Score".

## Интерпретация результатов

- **Рост общей награды:** свидетельствует об улучшении стратегии агента.
- **Уровень сотрудничества:** высокий процент взаимного доверия (кооперации) говорит о выработке устойчивой кооперативной стратегии.
- **Сравнение моделей:** позволяет определить, какая архитектура наиболее эффективна для данной задачи.

## Заключение

Проект демонстрирует применение методов из теории игр, обучения с подкреплением и нейронных сетей для решения сложных итеративных задач. Система позволяет экспериментировать с различными стратегиями, оптимизировать поведение агентов и проводить глубокий анализ результатов, что делает её отличным инструментом для исследований в области Data Science и машинного обучения.
